# 工作区 HTML UI 默认样式

确认人：不要菲斯哥。最新确认日期：2026-10-05（首次确认：2026-09-03）。

适用范围：整个工作区生成或维护的 HTML 格式 UI，包括静态页面、报告、审阅与确认页面、工具界面和 Web 应用页面。新页面默认继承这套已确认样式，不再默认重新选型；已有项目明确确认的其他视觉方向继续有效，用户明确要求重设计时再调整。历史页面不自动批量迁移。

## 工作台默认布局

适用于工具首页、项目工作台和集中审阅页面。按真实业务内容使用相应区块；报告、详情和时间轴继续按其信息结构组织。

1. 顶部导航：左侧名称，中间主栏目，辅助标签靠右；当前栏目使用深蓝文字。
2. 标题区：白底描边面板，左侧主标题、副标题及元信息，右侧主要操作；主标题粗体，副标题深蓝。
3. 阶段栏：有阶段流程时放在标题区下方，白底描边，各阶段用细线分隔，当前阶段用黄绿底；阶段名称和数量来自业务流程。
4. 核心内容：桌面采用左右两栏，`grid-template-columns: minmax(0, 2.1fr) minmax(0, 1fr)`，间距 `20px`。左侧白色卡片放审阅、预览或主要内容，右侧黄绿色卡片放待确认事项与行动按钮。
5. 次级内容：素材、文件或其他分类卡片放在核心内容下方；桌面三列，`grid-template-columns: repeat(3, minmax(0, 1fr))`，间距 `16px`。

## 组件与阅读层级

- 页面标题放在浅底描边面板；全篇总结等核心信息可用深蓝底、白字、青柠色小标题。
- 主按钮用深蓝底白字；次按钮用白底深色文字，保留直角描边及硬阴影。黄绿用于当前阶段、待办面板、编号和状态标签。
- 预览区域的 UI 外框使用浅灰蓝面板底色与细分隔线；其中的视频、图片和动画保持各自内容样式。
- 章节栏用深蓝底，编号用青柠色底；普通内容用白色卡片，避免大量颜色竞争。
- 编号、时间和来源定位使用等宽字体和蓝色；原文保持较大字号，辅助说明使用次级文字色。
- 时间轴适用于有顺序或时间关系的内容：按章节分组，组内以深色竖线和青柠色方形节点连接卡片。没有时间来源的内容不伪造时间码。
- 表格、清单或分镜详情按各项目或能力的信息架构组织，继承上述字体、配色、描边和间距即可；不为了复刻参考页面而改变业务字段或流程。

## 交互与窄屏

- 总览／详情切换、审阅弹窗和意见保存按各项目已确认流程实现；样式演示中的按钮不代表正式功能已经实现。
- 素材卡片悬停为 `#f5fbdc` 浅青柠底，并水平移动 `2px`；主按钮悬停使用 `var(--blue)`。整体保持轻量交互。
- 工作台以 `760px` 为窄屏断点：导航换行，标题与操作区转为上下排列，审阅／待办与素材卡片转为单列；主容器外侧留 `16px` 内容边距，卡片内边距约 `18–20px`，外层阴影减为 `3px 3px 0`。其他阅读页面可按内容调整断点。
- 章节头与字段行在窄屏转为单列，时间码移入卡片；保持自然纵向滚动，必要信息与操作仍须可达。

## 继承与验收

- 这份规范是 UI 展示层默认值，不修改语义协议、人工确认门禁或任何项目内容真源，视频画面、动画和成片信息组件本体仍按各自视觉规范执行，即使以 HTML 技术实现，也不因文件格式而套用本 UI 样式；承载它们的审阅页面适用本规范。
- 用户已确认本组合为工作区默认。新 HTML UI 直接继承完整样式，工作台同时继承上述布局；沿用时无需重新选型。用户明确要求重设计时，再按工作区设计路由执行。
- 基础剪辑语义文稿的内容验收 manifest 继续独立有效：其中 CSS 等属于内容契约的非规范项，不妨碍此处将同一 HTML 定为展示层默认。
- 后续实际实现 UI 时，检查核心视觉参数一致、业务字段完整、总览与详情可达、窄屏内容可读且可滚到底；验证强度按软件产品 QA 工作流选择。
- 验证记录（2026-10-05）：组合预览的桌面效果图已检查并获用户确认；本次规范更新核对参考文件版本、颜色、直角描边、硬阴影、字体及布局参数。组合预览本次未复验手机及交互，正式工作台的下载、归位、派发与真实影片流程未实施、未验证。
- 本次更新规范和继承入口，历史页面不自动改造，也不表示仓库外执行器已自动加载此规则。
