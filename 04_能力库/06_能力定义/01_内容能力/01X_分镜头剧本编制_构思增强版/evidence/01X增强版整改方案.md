## 1. 目标与边界

在现有 01X 的原文绑定、事实解释和逐句阅读任务上，增加借鉴 article-metaphor-illustrator 的构思过程：明确单一命题、原文特色线索、表达关系、视觉信息单位及揭示顺序，形成可审核的构思卡。

## 3. 构思流程

1. 通读全文并沿用已有事实解释，识别本段讲解任务和需要保留的前提、限定、关键关系。
2. 按一个可清楚复述的命题组织连续句组；可以一张卡覆盖多句，不强制每句切换隐喻。
3. 先判断流程、架构、对比、关系、结构或概念插图是否适合，再提出构思。隐喻不合适时采用直接表达。
4. 检查主对象、动作或关系、变化与结果，压缩无信息作用的装饰，区分完整信息和当前可揭示信息。
5. 对照逐句阅读任务核查构思的起始、推进、完成和衔接，再编译卡片及分镜交付，进行有限的人工可读性评审。

“一秒抓住主对象、三秒看懂关系”仅作为静态阅读启发，不转成固定播放时长。大对象重复宜少、重复细节宜分组作为建议，不机械按数量删除事实，也不复制上游存在歧义的总分门槛。

## 4. 数据契约设计

增强版拟使用独立身份：producer=`01XC`、输出 schema_version=`source01xc-storyboard.v1`、semantic plan schema_version=`storyboard-conception-plan.v1`、authority=`01XC_source_bound_interpretation`。这些是本方案拟定值，尚未实现或注册；不冒充旧契约、不新增旧身份兼容层。

第一阶段增强输入限定原版支持的 V3 稿件，复用其 narrative_tasks。V2 进入增强编译入口时明确报“不支持构思增强，请使用 V3 或原 01X”，不暗中生成阅读任务。原版 V2/V3 行为不变。

semantic plan 增加 `conception_cards`，每个句子按源顺序恰好属于一张卡，卡覆盖连续句段。直接表达也使用卡片 mode=`literal`，不强行制造隐喻。逐句原文及阅读任务仍完整覆盖；卡片只负责组织，不替代句子。

| 字段 | 内容与约束 |
| --- | --- |
| id / sentence_ids / mode | 唯一编号、连续句组、literal 或 metaphor |
| task / proposition | 本卡任务及一个主命题；不能借“单一命题”删掉必要条件 |
| source_cues | 带原文精确 source_span 的特色线索；不等同文件哈希 |
| fact_ids / required_fact_ids | 引用已定义事实；后者的完整性须与输入已有硬性要求及事实前提/限制对照，不能只信任作者自报 |
| representation | 图式类型、选择理由、主对象及其动作或关系 |
| metaphor_mapping | metaphor 模式逐项说明事实概念→画面载体、对应关系和适用边界；道具不是新的事实实体 |
| visual_units | 单位编号、角色（事实内容/隐喻载体/装饰）、支撑来源或映射引用、必要标签；事实内容必须有来源 |
| reveal_plan | 引用 sentence_id 和 reading_order 的零起始 beat_index；声明该拍呈现/保留/强调/移除哪些单位及完成状态 |
| continuity | 卡片进入条件、完成条件及跨卡保留单位，引用相邻卡和单位，禁止悬空引用 |
| economy | 重复对象的分组办法、删除装饰及原因，不允许据此删掉必需信息 |
| readability_review | 主对象、阅读顺序、关系可读性、原文辨识度的人工判断及理由；未审阅明确记为未验证 |
| downstream_notes | 可调整的构图建议和需要保留的表达意图；确认约束沿用既有来源，不凭卡片新增“已确认”约束 |

正式字段类型、枚举及条件必填规则在增强版契约中定义。事实和时序为硬约束；图式、隐喻载体、排列建议允许后续重构，但必须保留原意与信息出现权限。

信息权限由编译器结合精确 source_span、已有事实依赖和 reading_order 重算，不采信卡片自称“可以显示”。完整结论只在所需来源和前提全部讲到后显示；当前句只讲到部分时只能揭示有对应来源支持的部分。无法证明可提前呈现的单位延后至来源完整。仅记录“来自当前句”不足以获得句首完整显示权限。作者判断隐喻关系是否失真仍须人工审阅，结构校验不能替代。

揭示事件默认在所引用阅读拍的 `source_span.end` 到达后生效，不能在该拍起点展示拍尾才讲完的内容。需要更细揭示时由作者细分既有 reading_order 的连续原文片段，并继续满足原有完整覆盖校验，不新造时间轴或实际音频时间。按正文顺序重算真实可见单位集合：保留、强调只能作用于已可见单位，移除后不再可见；跨卡继承只能取前卡实际结束时仍可见的单位。卡片进入、完成和衔接必须满足所覆盖逐句任务的条件；存在结构或权限冲突时拒绝编译，需要语义判断的冲突退回人工修订，不覆盖 narrative_tasks。

承载事实含义的视觉单位和隐喻映射必须绑定已校验事实，并递归继承其 `evidence_uses`、前提和关系端点依赖。直接引文也必须满足同等证据用途检查；`understanding_only` 不能升级成观众可见事实，即使来源真实且已讲到。source_cues 只用于原文辨识度，不授予展示权限。标签、箭头、动作只要表达事实关系就受同样约束，不能标为装饰来绕过。
