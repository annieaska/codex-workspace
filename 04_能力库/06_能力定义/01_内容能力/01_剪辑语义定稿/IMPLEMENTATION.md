# 落地设计与迁移判定

## 最小设计

`NormalizedEditRequest → 剪辑语义定稿执行器 → SemanticBlueprint`

执行器只依赖两个显式参数：输入文件和组件目录。它不保存业务定义，也不内嵌组件目录；能力定义、协议、目录和验收案例留在本仓库，运行代码留在仓库外。

后续接入顺序：

1. 组件决策读取同一 `component-catalog.json`，给输入补充或校验组件选择。
2. 视觉合规读取候选蓝图，作为定稿前的内部质量门禁。
3. 字幕预演只读已定稿蓝图，输出独立派生目录。

## 旧资产逐项判定

| 旧资产 | 判定 | 依据 |
| --- | --- | --- |
| 剪辑语义定稿的制品信封、字幕覆盖、三幅画面和版本约束 | 保留设计重建 | 边界基本正确，但 Ruby 内嵌组件目录并引用旧绝对路径 |
| Ruby `semantic_edit_finalize.rb` | 不复制实现 | 与唯一组件真源冲突，且把静态 HTML/SVG 渲染绑进原子能力 |
| 组件决策 Node 实现 | 保留算法思路，后续重建 | 测试可运行，但再次硬编码目录，名称与 Ruby 目录不一致 |
| 视觉合规 Node 实现 | 保留规则思路，后续适配 | 测试可运行，但标准来源依赖旧绝对目录，尚未以蓝图为门禁输入 |
| 字幕动画预演 Node 实现 | 保留目标，重建接口 | 当前从 HTML 内嵌数据读取，不符合只读 `SemanticBlueprint` 的边界 |
| 旧 HTML、SVG、V1/V2 预演目录 | 不迁移 | 均为派生制品或重复生成物 |
| `.planning`、草案、`.DS_Store` | 不迁移 | 过期过程资料或系统杂项 |

## 暂未完成

- 组件推荐和选择校验服务尚未接入主链。
- 视觉合规门禁尚未接入主链。
- 字幕动画预演尚未按蓝图接口重建。
- 当前只支持创建 `V1` 蓝图；父版本修订与单单元重生成留待后续纵切。
