# 科学内容写作 SOP

提炼日期：2026-08-28

## 目标与适用范围

用于科普文章、口播稿和视频脚本。目标是让每个关键断言都有可追溯依据，并把“证据是否成立”和“对外能否这样表达”分开处理。

本 SOP 不替代医学、法律或其他专业审查；高风险主题发布前仍需具备相应资质的人复核。

## 最小交付物

一篇内容只维护四样东西，可写在同一项目工作文档中：

1. 选题卡：受众、平台、一句话价值与范围。
2. 断言—证据表：关键断言、来源、判断和局限。
3. 科学边界表：可说、条件化或禁止，以及替换表达。
4. 成稿与发布检查结果。

## 工作流程

### 1. 锁定问题和边界

- 写清目标受众、使用场景和期望解决的问题。
- 把主题改写成一个可核验的问题，不以预设结论开题。
- 列出必须回答、暂不回答和禁止越界的内容。
- 预先标出高风险表述：疗效、安全性、因果、比较、数字阈值和绝对化结论。

立项完成标准：陌生人能在一分钟内说清“给谁看、解决什么、不会承诺什么”。

### 2. 把素材拆成原子断言

一条断言只表达一个可核验事实。对每条断言记录：

| ID | 断言 | 类型 | 风险 | 需要什么证据 |
| --- | --- | --- | --- | --- |
| C-01 |  | 事实 / 机制 / 因果 / 数字 / 建议 | 低 / 中 / 高 |  |

重点拆分带数字、因果词、比较级、普遍化词语，以及“有效、无效、安全、最佳、一定”等结论。

### 3. 搜索并登记证据

- 先找指南、监管或权威机构材料，再找系统综述、临床研究和原始研究。
- 机制、小样本或观察性研究只能支撑相称强度的结论。
- 品牌页、供应商资料和商业材料只能证明其自身声称或参数，不能独立证明疗效。
- 每个来源记录标题、机构或期刊、年份、链接、研究对象、条件、结论和主要局限。
- 搜不到足够依据时标记“证据不足”，不靠常识补齐。

证据等级不是固定字母标签；应按当前问题判断来源与断言是否直接匹配。

### 4. 逐条核查断言

| ID | 核查结果 | 直接依据 | 适用条件 | 局限 | 处理 |
| --- | --- | --- | --- | --- | --- |
| C-01 | 成立 / 部分成立 / 不成立 / 证据不足 |  |  |  | 保留 / 降级 / 删除 / 补证 |

核查时同时问：

- 来源是否真正研究了稿件中的人群、剂量、产品、结局和时间尺度？
- 相关性是否被写成因果？体外或动物结果是否被外推到人体？
- 单一研究是否被写成共识？相对变化是否被误写成绝对效果？
- 原文中的不确定性、冲突结果和限制是否被保留？

### 5. 锁定科学表达边界

证据核查回答“对不对”，边界锁定回答“能不能这样说”。每条高风险断言只能进入以下状态之一：

| 状态 | 使用规则 |
| --- | --- |
| 可说 | 证据与表达强度匹配，可保留来源和适用条件后使用 |
| 条件化 | 加研究类型、人群、剂量、时间、对照或不确定性限定语后使用 |
| 禁止 | 当前证据不支持，正文不得出现；需要时改写成“尚不确定” |

常见降级方式：

- “证明、导致”改为与研究设计相符的“观察到、相关、可能影响”。
- “所有人、一定、完全”改为明确人群与条件。
- “更好”必须写明对照对象和评价指标。
- 品牌数据必须明确归因，不写成独立验证结果。
- 固定阈值必须有直接依据；否则保留为范围、不确定性或删除。

### 6. 写稿并保持可追溯

- 先按读者问题组织结构，再把已通过边界锁定的断言填入正文。
- 不在写作阶段临时增加未经核查的新事实。
- 引用应紧邻对应断言；同一引用不能替代对多条不同断言的核查。
- 口语化只能改变表达形式，不能放大确定性或删除限定条件。
- 写作产生新疑点时，返回步骤 3 补证，不凭感觉放行。

### 7. 发布前门禁

- [ ] 核心结论均能回到断言—证据表。
- [ ] 高风险断言均有核查结果和表达状态。
- [ ] 证据不足、不成立和禁止项未进入正文。
- [ ] 因果、比较、数字、适用人群和研究条件没有被夸大。
- [ ] 商业来源已明确归因，未被当作独立疗效证据。
- [ ] 链接、标题、年份和引用对应关系可复查。
- [ ] 标题、封面和摘要没有比正文更绝对。
- [ ] 高风险主题已完成必要的专业复核。

任一核心项未通过，不进入发布。

## 来源与提炼说明

本 SOP 用自己的话从既有的选题研究、文献核查、脚本结构和科学边界方法中精选提炼，未复制具体项目文稿，也不依赖旧目录或旧版本文件。
