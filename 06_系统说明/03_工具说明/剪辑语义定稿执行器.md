# 剪辑语义定稿执行器

## 索引

- 能力：`video.semantic_blueprint.finalize`
- 能力定义：`04_能力库/06_能力定义/01_内容能力/01_剪辑语义定稿/`
- 当前执行器：`/Users/chengyu/.local/share/codex-tools/semantic-blueprint/semantic-blueprint.mjs`
- 当前运行时：Node.js 18 及以上，仅使用内置模块

执行器不保存业务定义，也不内嵌组件目录。更换执行器时，能力定义、协议、组件目录和验收案例不随之迁移。

## 执行

在业务仓库根目录运行：

```sh
CAPABILITY_DIR="$PWD/04_能力库/06_能力定义/01_内容能力/01_剪辑语义定稿"
node /Users/chengyu/.local/share/codex-tools/semantic-blueprint/semantic-blueprint.mjs \
  --input "$CAPABILITY_DIR/acceptance/hard-sun-protection/input.json" \
  --catalog "$CAPABILITY_DIR/component-catalog.json" \
  --output /tmp/hard-sun-protection.semantic-blueprint.json
```

输出路径必须不存在；执行器拒绝覆盖已有蓝图。`--created-at` 仅用于可重复测试，正常执行不传。
