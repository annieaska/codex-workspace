# 临时输出

无项目任务使用 `日期_任务名/`；项目任务使用各自 `02_工作区/99_临时/日期_任务名/`。

- `浏览器自动输出/主工作区/`：Playwright 默认命名的截图、快照与日志。需要归档的证据由任务转入项目工作区或成果包。
- `2026-09-20_目录整理/`：本次整理的核验脚本和最小输出样例。
- `90_迁移恢复/2026-09-20_目录整理/`：本次迁移的只读原件及精确清单；当前必须保留，不能按普通临时文件清理。

临时不等于可删除。唯一原件、成果未归档、用途未明或仍被引用的文件先保留，清理前核对用途、依赖与恢复条件并取得用户授权。完整迁移结果只维护在 [原整理计划](../00_工作台/工作区目录整理与迁移计划.md)。
