# 打工人程宇业务工作区

这是个人业务工作区的最小基座，用于承载业务运行、项目、知识、能力模板、人工确认记录和系统说明。

本工作区是业务资料真源；Memmy 仅作为运行层，不是业务真源。各项目的 `PROJECT.md` 是项目状态与决策的权威入口。

## 使用入口

- 临时输入进入 `00_工作台/01_收件箱`。
- 业务材料按用途进入 `01_业务运行`。
- 有明确目标和交付物的工作进入 `02_项目`。
- 可复用知识、方法和模板分别沉淀到 `03_知识库` 与 `04_能力库`。
- 只有人工确认后的事实、偏好、决策和经验进入 `05_确认记录`。
- 环境与工具说明进入 `06_系统说明`，不得保存任何密钥。
