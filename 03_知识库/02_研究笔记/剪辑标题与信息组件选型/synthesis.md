# 口播科普标题与逻辑组件：购买结论

## 结论

不建议购买 Boris FX、Red Giant 或大型转场订阅。当前视频形态是“口播人物 + 信息组件”，真正需要的是两类标题和六类逻辑组件。

### 推荐组件清单

1. 章节标题
2. 人物信息条 / 结论标题
3. A/B 对比
4. 步骤 / 信息卡
5. 判断分支
6. 因果链 / 原理流程
7. 数字 / 量表
8. 证据 / 来源卡

## 购买路线

### Premiere Pro 主剪

首选 Mister Horse Animation Composer。先安装免费版，用真实中文标题和常用中文字体做压力测试；确认不掉字、不挤压后，再考虑订阅。它覆盖标题、文字框、计数器、图形和排版动画，最接近当前需求。官方说明文字预设可使用任意文字、任意字体，但没有单独承诺 CJK，因此必须先实测。

### DaVinci Resolve 主剪

首选 Resolve 原生 Text+ / Fusion Title 作为中文底座。Blackmagic 官方明确写明 Fusion 支持完整 Unicode、TrueType/OpenType 字体，中文可靠性证据比第三方模板更充分。若需要一次性购买成品外观，可选 MotionVFX mTutorial DVR；它包含比较、标注、信息展示等 107 个预设，但官方没有明确 CJK 保证，且其中一部分教程/屏幕演示组件对护肤科普并非刚需。

### 两个软件都要用

不要假设同一套模板文件能跨 Premiere 和 Resolve。多数商城按宿主提供不同版本，MotionVFX 的 Pr 与 DVR 版本也是分开购买。建议只在主剪软件维护可编辑模板；另一软件使用 ProRes 4444 透明通道动画、PNG/SVG 或成片。
