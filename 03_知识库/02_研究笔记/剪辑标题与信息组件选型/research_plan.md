# 口播科普标题与信息组件套装筛选

## 目标

为“口播人物 + 信息组件”的中文科普视频，筛选简单、中文输入稳定、标题好看、能表达逻辑关系的 Premiere Pro / DaVinci Resolve 方案。

## 约束

- 不需要复杂转场、粒子或电影特效。
- 优先少量高复用组件，而非大型特效全家桶。
- 核验中文字体与文本可编辑性、学习成本、宿主兼容性和价格。
- 双软件优先保持视觉规范一致，不假设模板文件可以跨宿主直接复用。

## 分题

1. Premiere Pro：中文文本、标题和信息组件、操作复杂度。
2. DaVinci Resolve：中文文本、标题和信息组件、操作复杂度。
3. 双宿主：购买与授权、模板可移植性、低成本组合。
4. 项目映射：对照现有画面形态和 component catalog 给出最小组件清单。

## 交付标准

- 最多推荐 3 个方案。
- 明确首选、次选与不推荐购买项。
- 给出购买前中文压力测试清单。
