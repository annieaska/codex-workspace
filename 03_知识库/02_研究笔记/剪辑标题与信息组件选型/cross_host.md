# Premiere Pro + DaVinci Resolve 双宿主低复杂度购买策略

> 核验日期：2026-09-03。仅采用 Motion Array、Envato、MotionVFX 官方商品页、帮助中心与许可条款。价格和兼容版本会变化，购买当天仍应以商品页为准。

## 一句话结论

不要把“平台同时有 PR 与 Resolve 素材”理解成“同一个模板文件可在两边打开”。Premiere 的项目／MOGRT／预设与 Resolve 的模板／宏／项目是宿主原生资产，通常要分别下载、分别安装；有些厂商甚至要分别购买。真正适合“一份资产两边用”的，主要是普通视频、透明通道视频、图片、音效／音乐、字体，以及经商品说明确认的通用 LUT。

最低复杂度的做法是：**选一个主剪辑宿主使用可编辑模板；另一宿主只使用通用素材或已经渲染好的图形。** 只有确实需要在两边继续修改同一视觉样式时，才买／下载各自的原生版本。

## 平台核验

### 1. Motion Array：一个订阅能访问两类目录，但模板文件不跨宿主

- 官方兼容说明明确把 Premiere 模板与 DaVinci Resolve 模板分开：Premiere 模板需要 Premiere Pro，MOGRT 需要相应版本的 Premiere；Resolve 宏与模板需要 Resolve。由此可知，订阅覆盖的是素材库访问权，不是统一文件格式。[官方宿主要求](https://help.motionarray.com/hc/en-us/articles/9059011775645-What-Software-Will-I-Need-In-Order-Use-Your-Templates)
- 同一设计有时会提供 Premiere、Resolve、After Effects、FCP 等“其他版本”链接，但它们是独立版本，不是同一文件直接跨宿主打开。例如 Modern Opener 商品页把不同宿主版本分别列出。[官方示例商品页](https://motionarray.com/davinci-resolve-templates/modern-opener-855446/)
- 付费期间下载的素材可用于个人和商业项目，也可以交付客户的衍生作品；不能把原始素材单独转交、转售或让客户提取。账户只供一位用户使用。[许可说明](https://help.motionarray.com/hc/en-us/articles/9442171935005-How-Does-The-License-Work)｜[客户项目说明](https://help.motionarray.com/hc/en-us/articles/25247349475997-Does-the-license-cover-client-use)
- 取消订阅后，已在订阅有效期内完成并发布的作品仍受许可保护，但不能把已下载素材用于新项目。[降级／取消后的许可](https://help.motionarray.com/hc/en-us/articles/8956144685469-What-Happens-If-I-Downgrade)
- 特别注意 Motion Array 自家的效果插件：官方故障说明称订阅失效后会出现水印，重新打开旧工程也可能受影响；最终已渲染的视频不受影响。因此，不宜把订阅插件作为需要多年返修的工程依赖。[插件故障与订阅水印说明](https://help.motionarray.com/hc/en-us/articles/17704627083805-Troubleshooting-issues-with-plugins)
- 兼容还有安装环境限制：官方同一说明指出 Resolve 的 Mac App Store 版本不兼容 Motion Array 插件，应使用 Blackmagic 官网版本；Apple Silicon 某些情形可能需 Rosetta。购买前必须按当前宿主版本复核，不能只看“支持 Resolve”。[同上](https://help.motionarray.com/hc/en-us/articles/17704627083805-Troubleshooting-issues-with-plugins)

**判断：** 如果目标是一个月内集中下载 PR 与 Resolve 两套原生模板，Motion Array 可以降低采购次数；但后续要保存每个资产的宿主版本与许可记录。长期返修项目应优先使用模板或通用媒体，谨慎依赖退订即水印的插件效果。

### 2. Envato Elements：订阅覆盖广，但每个项目仍要单独许可

- Envato Elements 下载项会取得商业许可，可用于个人、客户和商业项目；但许可按一个项目／一个最终成品计算。相同素材用于另一个项目时，在订阅有效期间应重新登记／下载许可。“无限下载”不等于一次登记后无限项目复用。[订阅许可介绍](https://help.elements.envato.com/hc/en-us/articles/360000621483-Introduction-to-the-Envato-subscription-License)｜[创建新许可](https://help.elements.envato.com/hc/en-us/articles/360000621763-Create-new-license)
- 退订后，订阅期内已经完成的最终成品继续受许可保护；但不能将素材用于新项目，也不能继续未完成项目。官方 FAQ 还明确提示退订后不可再修改已完成的最终成品，因此长期需要更新的科普栏目不宜只保留可编辑的 Elements 依赖。[许可 FAQ](https://help.elements.envato.com/hc/en-us/articles/360000629346-Envato-Elements-License-FAQ)｜[取消订阅](https://help.elements.envato.com/hc/en-us/articles/360000621563-Cancel-Your-Subscription)
- 不能把源文件或可提取的素材直接交给客户。可以把完整最终成品交付客户，但需限制客户对原始素材的使用与提取。[正确使用方式](https://help.elements.envato.com/hc/en-us/articles/360000621783-Correct-Usage-of-Items)｜[禁止用途](https://help.elements.envato.com/hc/en-us/articles/360000621803-Prohibited-Usage-of-Items)
- 官方视频使用提示要求购买／下载前检查宿主与软件版本，尤其是 DaVinci Resolve；这与平台分别提供 Premiere Pro、DaVinci Resolve 兼容筛选相符。即使视觉预览相同，也要把两个宿主版本视为不同工程资产。[视频素材使用提示](https://help.elements.envato.com/hc/en-us/articles/22194398651417-Video-Tips-Tricks)｜[Premiere Pro 兼容目录](https://elements.envato.com/video-templates/compatible-with-premiere-pro)｜[DaVinci Resolve 兼容目录](https://elements.envato.com/video-templates/compatible-with-davinci-resolve)
- 模板演示中出现的照片、视频、音乐或字体不一定包含在下载许可中；官方要求检查 Documentation／Licensing 文件夹和商品说明，不能把预览片里的所有内容当成已买到。[订阅许可介绍](https://help.elements.envato.com/hc/en-us/articles/360000621483-Introduction-to-the-Envato-subscription-License)

**判断：** Envato 适合在短期内筛选大量候选，并且同一订阅分别取得 PR 与 Resolve 的原生资产；它不适合“退订后仍反复修改旧栏目”的工作方式。应在有效期内把每个实际项目完成并导出，同时保存项目许可凭证。

### 3. MotionVFX：产品页写三个宿主，也可能是三个独立版本、三次购买

- MotionVFX 条款把 Host Software 定义为“每个产品页面指定的兼容软件”，并明确说明并非一个产品的所有元素都为所有宿主发布。因此，不能因为官网导航同时列出 Premiere 与 Resolve，就推断一份购买包含两个宿主。[官方条款](https://www.motionvfx.com/conditions)
- 官方 mMusic Video 2 是最直观的反例：同一视觉系列宣传支持 FCP、Resolve、Premiere，但技术规格分别列出三套不同内容。Resolve 版为 16 个标题、35 个效果、10 个转场；Premiere 版为 51 个标题、10 个转场且要求 Premiere Pro 2023+ 与 After Effects 2023+；页面分别显示 “Buy for DaVinci Resolve $109” 和 “Buy for Premiere Pro $109”，还提示各版本可能有轻微视觉差异。[mMusic Video 2 官方商品页](https://www.motionvfx.com/store,mmusic-video-2-pr,p4243.html)
- mInstaller 能把购买内容安装到对应剪辑软件，但官方措辞是“depending on your order”，即安装到哪个宿主取决于订单内容；安装器支持多个宿主，不代表订单自动包含多个宿主。[官方安装说明](https://support.motionvfx.com/en/articles/9099828-how-to-install-motionvfx-products)
- 单次购买与订阅的权利不同：官方条款规定，独立购买的许可期限为无限期；订阅产品只在订阅期内可用，订阅结束后许可终止并须停止使用／销毁副本。每份许可限本人在一台主设备和一台本人拥有的副设备上使用，不能转让或共享。[官方条款 Appendix A](https://www.motionvfx.com/conditions)
- 数字产品原则上不退款、不换货（法定消费者权利除外），所以更需要先核对商品页的宿主、最低版本、系统、显存与是否依赖 After Effects。[官方条款](https://www.motionvfx.com/conditions)

**判断：** MotionVFX 不应作为“买一套，两边通用”的默认方案。它更适合已经选定主宿主后，按单个高频工具永久购买。若产品确有 PR／Resolve 两版，应把它们视为两个 SKU；只有结账页明确打包两版时，才能算一次购买覆盖双宿主。

## 中文科普项目的实际风险

以下前两项有官方直接依据；其余是根据官方宿主／版本与素材包含规则作出的工作流推论，购买前应以免费样例或商品页实测。

1. **字体并非小问题。** MotionVFX 官方记录过字体重复或字体数据库损坏会导致 Resolve 插件黑屏；即便不是中文专属问题，也说明字体是模板运行依赖。[官方故障说明](https://support.motionvfx.com/en/articles/6161578-i-can-t-see-your-motionvfx-plugins-in-davinci-resolve-timeline)
2. **预览字体和演示媒体可能不包含。** Envato 明确要求查看 Documentation／Licensing 文件；缺字库、另购字体或仅有拉丁字符会直接破坏中文标题版式。[Envato 许可介绍](https://help.elements.envato.com/hc/en-us/articles/360000621483-Introduction-to-the-Envato-subscription-License)
3. **“可输入文字”不等于“适合中文”。** 固定宽度、逐字动画、英文大小写与字距设计，换成中文后可能出现缺字、截断、换行、行高或动画节奏异常。下载前至少实测“科学解释：为什么会这样？”、“第一步／第二步”和两行长标题。
4. **Premiere 版可能额外依赖 After Effects。** MotionVFX 的同一产品实例就明确要求 Premiere 2023+ 与 After Effects 2023+；只装 Premiere 并不一定能用。[mMusic Video 2 技术规格](https://www.motionvfx.com/store,mmusic-video-2-pr,p4243.html)
5. **同名跨宿主版本不保证功能、比例和视觉完全一致。** 上述 MotionVFX 商品页的两版元素数量和横竖屏能力就不同。跨软件复刻栏目包装时，应该先确定“视觉一致到什么程度”，不要假定参数可以一一对应。[同上](https://www.motionvfx.com/store,mmusic-video-2-pr,p4243.html)

## “买一套两边用”的常见误区

| 误区 | 实际情况 | 购买前检查 |
|---|---|---|
| 平台同时支持 PR 和 Resolve，所以模板通用 | 平台有两个宿主目录，不代表一个文件跨宿主 | 商品页是否分别列出 Pr／DVR 版本和下载按钮 |
| 同名模板就是同一个产品 | 可能是独立工程、独立 SKU，甚至元素数量和功能不同 | 技术规格、包含数量、宽高比、依赖项、结账购物车 |
| mInstaller／平台扩展支持多软件，就等于一份许可多宿主 | 安装器只负责管理已购买的对应版本 | 订单明细与具体产品页，而不是安装器介绍 |
| 无限下载等于永久无限使用 | Motion Array／Envato 退订后均限制新项目；MotionVFX 订阅许可期满即终止 | 退订后能否新建、返修、重开旧工程、是否加水印 |
| 已渲染视频和可编辑工程的风险一样 | 渲染成品通常更稳定；插件或订阅模板可能让旧工程返修失败或带水印 | 长期项目应保存无依赖母版和透明通道渲染件 |
| PR 与 Resolve 之间 XML／AAF 交接会带走模板和插件 | 这是宿主原生效果，通常不会可靠迁移；这是基于上述宿主专用格式的工作流推论 | 跨软件前 Render and Replace／导出带 Alpha 的中间件 |
| 英文预览漂亮，中文替换也会一样 | 字形覆盖、行高、逐字动画、文本框宽度都可能不适合中文 | 用真实中文标题试用，核对字体授权与是否包含 |

## 推荐购买路径（按复杂度从低到高）

### A. 最推荐：一主一辅

1. 先决定栏目包装在哪个宿主维护，模板只买该宿主版本。
2. 两边共享的资产只选通用媒体：视频／透明通道视频、PNG／SVG、音效／音乐、已确认兼容的字体和 LUT。
3. 另一宿主需要相同包装时，从主宿主导出高质量成片或带 Alpha 的图形中间件，不继续保持模板可编辑性。

这是成本、返修风险和文件管理复杂度最低的方案。

### B. 确实要两边都可编辑：分别获取原生版本

1. 优先选择商品页明确同时列出 PR 与 DVR 版本的同一设计系列。
2. 在购买／下载前逐项比较两版：元素数量、横竖屏、最低版本、系统、显存、AE 依赖、是否需要 Studio 版、中文字体。
3. 把两版视为独立资产管理，不能承诺控制项、时间线或效果完全一致。
4. MotionVFX 必须确认购物车是否包含两个 SKU；Motion Array／Envato 则要分别下载两个宿主版本，并分别保存来源与许可凭证。

### C. 订阅的最省钱使用法

- 不同时订 Motion Array 与 Envato。先按一个月订阅测试真实栏目，建立 10–20 个高频资产的小型核心库。
- 每个实际视频保存：素材 URL、下载日期、项目／许可登记、宿主版本、字体及第三方媒体说明。
- 退订前完成并发布对应作品，同时导出无插件依赖的母版、透明通道动画与静态备份。需要长期反复更新的栏目，优先换成永久购买或自制原生模板。
- MotionVFX 只为确认高频复用的工具做单次永久购买；若只是偶尔用一次，不值得为 PR 与 Resolve 各买一份。

## 最终采购建议

- **只想快速做科普视频：** 选 Motion Array 或 Envato 其中一个月，模板只围绕主宿主下载；通用素材两边共用。
- **需要多年返修同一栏目：** 避免依赖退订后水印／停止授权的插件；关键标题与信息图做成本地原生模板，并保存渲染备份。
- **看中 MotionVFX 某套包装：** 仅在商品页明确宿主、版本和中文实测通过后购买；默认按 PR 版与 DVR 版分别计价，而不是期待一次购买双宿主。
- **购买前最小验收：** 用真实中文长短标题、两行文本、横版与竖版各测一次；关闭网络并重启宿主再打开工程；确认无缺字、无黑屏、无水印、无额外 AE／Studio 依赖，再决定是否扩购。
