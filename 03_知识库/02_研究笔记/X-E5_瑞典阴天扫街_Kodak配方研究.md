# 富士 X‑E5：瑞典阴天扫街的 Kodak 配方选择

## 结论

首选 **Reggie’s Portra（X‑Trans V 调整版）**。它不是色彩最夸张的一套，却最符合“瑞典阴天、长时间扫街、偶尔进入室内、兼拍风景”的实际使用方式：自动白平衡能适应云层厚度与混合光变化，柔和的高光和阴影曲线保留灰天层次，`Clarity 0` 不会给连续抓拍增加额外的逐张处理时间。对 X‑E5 这类第五代机型，只需把原配方的 Color Chrome FX Blue 从 Weak 改为 Off，蓝色表现会更接近原来的第四代版本。¹

如果只装一套，就装它；如果用满 X‑E5 的 FS1–FS3 三个配方位，建议如下：

| 位置 | 配方 | 最适合 | 主要区别 |
|---|---|---|---|
| FS1 | Reggie’s Portra，X‑Trans V 版 | 阴天街拍、天气变化、室内外穿梭 | 最稳定、反应最快、人物肤色自然 |
| FS2 | Kodak Pro 400 | 纯户外阴天、港口、建筑与风景 | Reala Ace 基底，灰天更通透，蓝色更突出 |
| FS3 | Kodak Portra 400 v2 | 偶尔放晴、低角度阳光、金色时刻 | 最经典的暖调 Portra 印象，但阴天通用性稍弱 |

## FS1：主配方——Reggie’s Portra（X‑Trans V 调整版）

| 项目 | 设置 |
|---|---|
| Film Simulation | Classic Chrome |
| Dynamic Range | DR Auto |
| Highlight | −1 |
| Shadow | −1 |
| Color | +2 |
| High ISO NR | −4 |
| Sharpness | −2 |
| Clarity | 0 |
| Grain Effect | Weak / Small |
| Color Chrome Effect | Strong |
| Color Chrome FX Blue | **Off**（X‑E5 调整项） |
| White Balance | Auto，R +2 / B −4 |
| ISO | Auto，最高 ISO 6400 |

原配方采用 Classic Chrome、DR Auto、柔和两端曲线与自动白平衡；作者后来明确说明第五代机型（包括 X‑E5）可以继续使用，若希望更接近第四代色彩，把 Color Chrome FX Blue 降一档至 Off。¹ 这也是三套中最适合街拍的一套：非零 Clarity 会增加每张照片的保存时间，而本配方为 0。富士 X‑E5 官方手册也明确说明 Clarity 非 0 会增加保存时间。²

### 瑞典阴天实拍起点

- 普通灰天街道：曝光补偿从 **+1/3 EV** 开始。
- 人脸在帽檐、屋檐或背光下：尝试 **+2/3 EV**。
- 湿路面、深色建筑、夜色将近：从 **0 EV** 开始，避免把黑色抬成灰色。
- 雪地占画面大部分：通常需 **+2/3 至 +1⅓ EV**，同时看高光警告，雪面刚不过曝即可。
- 天空占比很大、想保云层：从 **0 至 −1/3 EV** 开始；人物较暗时宁可换构图，不要只靠压曝光。

曝光补偿不是配方的固定组成。原作者也强调每个画面应单独判断，而不是机械固定在某个正补偿值。¹

## FS2：阴天风景备选——Kodak Pro 400

| 项目 | 设置 |
|---|---|
| Film Simulation | Reala Ace |
| Dynamic Range | DR400 |
| Highlight | −2 |
| Shadow | 0 |
| Color | +1 |
| High ISO NR | −4 |
| Sharpness | −2 |
| Clarity | −2 |
| Grain Effect | Strong / Small |
| Color Chrome Effect | Off |
| Color Chrome FX Blue | Strong |
| White Balance | 5200K，R +2 / B −3 |
| ISO | Auto，最高 ISO 6400 |
| 曝光补偿起点 | +1/3 至 +1 EV，按现场调整 |

这是专为第五代传感器编写、明确兼容 X‑E5 的配方。作者认为它在日光下表现最好，并特别指出它可能比其他 Portra 配方更适合阴天。³ Reala Ace、Highlight −2 与 DR400 能让灰云、高反差水面和浅色建筑更从容；强蓝色效果则更适合瑞典港口、湖面和阴云间的蓝色。

代价有两个。第一，固定 5200K 在室内暖灯或蓝调时段不如 AWB 灵活。第二，Clarity −2 会增加保存时间，因此它更适合风景和节奏较慢的街景，不是迎面人物连续抓拍的首选。²

DR400 在 X‑E5 上要求 ISO 至少为 500；这是正常工作机制，不是设置错误。富士说明 DR400 用更高感光度换取高光余量，X‑E5 的可用范围为 ISO 500–12800。⁴

## FS3：经典暖调备选——Kodak Portra 400 v2

| 项目 | 设置 |
|---|---|
| Film Simulation | Classic Chrome |
| Dynamic Range | DR400 |
| Highlight | 0 |
| Shadow | −2 |
| Color | +2 |
| High ISO NR | −4 |
| Sharpness | −2 |
| Clarity | −2 |
| Grain Effect | Strong / Small |
| Color Chrome Effect | Strong |
| Color Chrome FX Blue | Off |
| White Balance | 5200K，R +1 / B −6 |
| ISO | Auto，最高 ISO 6400 |
| 曝光补偿起点 | +1/3 至 +1 EV，按现场调整 |

这是已有明确 X‑Trans V 版本的 Portra 400 v2。第五代版本将 Color Chrome FX Blue 调为 Off，以修正 Classic Chrome 在第五代传感器上更深的蓝色。⁵ 它拥有三套里最明显的暖色和柔软阴影，适合短暂放晴、秋叶、砖墙、人物以及日出日落；原作者尤其推荐在金色时刻使用。⁵

它并非瑞典纯灰天的第一选择：固定 5200K 与 B −6 会形成显著暖调，厚云下可能漂亮，也可能让雪、灰墙和白色建筑偏奶黄。遇到这种情况不要修改整套配方，先改用 FS1；这样能保持每个预设的视觉一致性。

## 为什么主配方不是“参数最像 Portra”的那套

真实 Kodak Portra 400 的核心不是单一橙黄色滤镜，而是自然肤色、较低饱和度、细颗粒及广泛光照适应性；Kodak也将其定位于人物、旅行、自然和不可控光线。⁶ 官方数据表还专门给出明亮阴天、重阴和开放阴影的曝光条件，说明它本来就是面向多种自然光工作的日光片。⁷

因此，在瑞典阴天扫街这一目标下，稳定的白平衡、柔和反差与快速响应，比强行固定某个暖色温更接近 Portra 的使用精神。Reggie’s Portra 是三者里最平衡的实现；Kodak Pro 400 更适合突出环境与天空；Portra 400 v2 则负责经典暖调。

## X‑E5 录入方法

X‑E5 的胶片模拟拨盘有三个独立配方位 FS1、FS2、FS3。进入：

`MENU/OK → IMAGE QUALITY SETTING → FILM SIMULATION DIAL SETTING → FS1/FS2/FS3 → FS RECIPE`

逐项录入后按 `DISP/BACK` 退出保存。富士官方说明，这三个位置能分别记录胶片模拟、颗粒、白平衡、色调曲线、色彩与锐度等画质设置。⁸

建议拍摄格式用 **Fine + RAW**。JPEG 直接使用配方；碰到雪地曝光、混合灯光或极端蓝调时，RAW 可在机内重新套用白平衡、胶片模拟、色调、颗粒等设置，不必把一次失误变成废片。X‑E5 官方手册列出了完整的机内 RAW 转换项目。⁹

## 最小试拍方法

第一次录入后，不需要做复杂测试。同一地点各拍三类画面即可：有人脸的街景、灰云加建筑、绿植或红砖。每套各拍 0 与 +2/3 EV，并在手机和常用显示器上看：

- 白墙和雪是否过黄；
- 阴影是否仍有黑位，而不是整体灰蒙；
- 人脸是否红得过头；
- 天空蓝色是否抢过主体。

若只能保留一套，依据不是哪张样片最惊艳，而是哪套在十张不同光线照片中失败最少。按现有配方结构与 X‑E5 特性，预期仍会是 FS1。
