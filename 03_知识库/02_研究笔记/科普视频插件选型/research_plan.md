# PR / DaVinci 科普视频插件套装调研计划

## 主问题

寻找适合科普口播项目、优先同时支持 Adobe Premiere Pro 与 DaVinci Resolve 的插件套装；付费可接受，并给出明确采购优先级。

## 子课题

1. 跨宿主综合套装：核验插件覆盖范围、Premiere Pro / DaVinci Resolve 兼容性、授权方式与当前价格。
2. 科普视觉表达：重点核验字幕、标题、标注、数据图表、信息图形和简洁转场等实际能力。
3. 后期质量与效率：核验音频修复、降噪、调色、人像处理和工作流增强插件，区分必需与锦上添花。

## 综合方式

优先采用厂商官网和官方帮助文档，按“科普适配度、双软件兼容、学习成本、授权成本、与现有能力重叠”比较，最后形成首选、备选与不建议优先购买清单。
