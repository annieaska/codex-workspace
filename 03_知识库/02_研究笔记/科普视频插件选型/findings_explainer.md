# 科普视频信息图形与标题包装套装调研

调研日期：2026-09-03  
范围：信息图形、动态图表、文字标注、字幕样式、呼出线、标题/栏目包装；优先核验 Premiere Pro 与 DaVinci Resolve 双宿主兼容及商用授权。

## 先说结论

1. **要“一次订阅、两边都有大量现成素材”**：优先看 **AEJuice All Access** 或 **Motion Array**。AEJuice 的科普组件更集中，但 Resolve 版大量内容以透明背景预渲染视频交付，未必像 Premiere 原生模板那样可深度改字、改数值和改动画。
2. **要“同一套效果系统在 Premiere 与 Resolve 里保持风格一致”**：优先 **Boris FX Continuum + Title Studio**。这是本轮核验中跨宿主属性最明确的一组，但更像专业动效工具箱，不是开箱即用的海量科普信息图模板库；购买前必须确认所选许可证/SKU 同时覆盖 Adobe 与 Resolve/OFX。
3. **要“素材选择最大、按项目不断换风格”**：**Motion Array** 比较省心，**Envato Elements** 的信息图和呼出线供给也很丰富。两者通常是分别下载 Premiere 版和 Resolve 版，不应理解成同一模板文件可在两个软件中互换。
4. **只以 Premiere 为主、追求最快套包装**：**Mister Horse Animation Composer** 很适合标题、计数器、图标、形状和排版动画，但没有核验到官方 Resolve 支持，不能当双宿主方案。

## 1. AEJuice：科普组件最集中，但 Resolve 版有关键限制

值得关注的内容包括 Callouts Pack、Infographic Pack、Corporate Infographics Constructor、Corporate Infographics、标题、文字动画、图标和常用 VFX。Premiere Bundle 官方列出 126 个产品；Resolve Bundle 列出 83 个产品。All Access 官方标注 100,000+ 动画资产，并写明包含商业许可。

关键区别：Resolve Bundle 官方明确写的是，所含产品以“带透明背景的预制视频”形式兼容 Resolve。因此它更适合直接叠加箭头、强调动画、装饰性呼出和标题，不宜默认认为每个图表的数据、颜色、文字和关键帧都能在 Resolve 内原生编辑。需要动态改数值、中文字段或品牌色时，应先下载样例或购买前询问具体包的 Resolve 交付形式。

## 2. Motion Array：最适合长期找不同主题素材

Motion Array 官方把 Premiere Pro 和 DaVinci Resolve 分成独立模板类别。Premiere 分类可直接筛选 titles、lower thirds、infographics、overlays/icons；Resolve 则使用对应的 Resolve 模板或宏。库存视频、motion graphics、图片与音频属于更通用的媒体资产，才更容易在两个软件间共用。

授权方面，多数素材可用于商业项目，但标记为 Editorial Use Only 的素材不能用于商业宣传；不可把下载文件本身重新分发。官方帮助页说明：在有效订阅期间创建并发布的成品，退订后仍受许可覆盖；退订后不能继续把以前下载的素材用于新项目。单用户许可和企业许可也有适用边界，大型组织、广播等用途应核对 Business 方案。

## 3. Envato Elements：图表与呼出线丰富，许可要按项目登记

## 4. Boris FX Continuum / Title Studio：真正的双宿主效果系统

## 推荐采购路径

### 路径 A：最低试错成本

先订阅 **Motion Array 1 个月**，分别挑一套 Premiere 和 Resolve 的同风格标题、呼出线、图表模板，实际测试中文字体、4K、竖屏和改色效率。适合还没确定长期视觉风格的项目。

### 路径 B：高频科普、追求组件数量

选择 **AEJuice All Access**，以 Premiere 作为主要深度编辑宿主；Resolve 端优先把资源当作透明动效叠加层使用。下单前抽查 3 类核心资源：可改文字的呼出线、可改数值的图表、可换中文字体的标题。

### 路径 C：两个宿主都要做长期统一栏目包装

选择 **Boris FX Continuum / Title Studio**，先做一套栏目母版：主标题、章节卡、lower third、术语框、数据高亮和转场。购买前书面确认一个许可证是否同时覆盖 Premiere 与 Resolve，以及允许安装的设备数量。

## 字幕的现实建议

上述产品中的“字幕”多数指动画字幕样式、标题模板或 speech bubble，并不等同于中文语音识别和自动断句。长篇科普字幕建议先用 Premiere 或 Resolve 的原生转录/字幕功能生成时间轴字幕，再把插件集中用于关键词高亮、术语解释、章节标题和少量强调句。这样可读性与修改效率通常高于给整条逐字字幕套复杂动画。

## 本轮未列入主推荐的候选

- **MotionVFX**：本轮官方检索未拿到足以确认“同一套产品同时支持 Premiere 与 Resolve”的证据，因此不做跨宿主推荐。
- **Storyblocks**：本轮没有完成官方宿主模板兼容与许可细则的双重核验，因此不与上述候选并列。

## 购买前统一检查清单

- 是否为同一模板/插件跨宿主，还是分别提供两个宿主版本。
- Resolve 版是原生 Fusion 模板、宏，还是透明背景预渲染视频。
- 是否能直接输入中文、替换字体、修改数据与品牌色。
- 4K、竖屏、不同帧率下是否正常；是否依赖 After Effects 或第三方插件。
- 商用范围是否覆盖客户项目、YouTube/抖音/视频号变现、广告投放和团队协作。
- 退订后已发布项目是否持续授权，旧下载能否用于新项目。
- 是否禁止交付源模板、是否要求每个成品重新登记许可。
