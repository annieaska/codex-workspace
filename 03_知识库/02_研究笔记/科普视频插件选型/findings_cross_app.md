# Premiere Pro / DaVinci Resolve 双平台插件套装调研

调研日期：2026-09-03。优先采用厂商官网、官方帮助中心和官方价目表。价格均可能因地区、税费、汇率和促销变化；下文美元金额应在付款前以购物车为准。

## 先给结论

1. **要“一次购买、PR 和达芬奇都能装”的综合套装：首选 Boris FX Continuum Multi-host。** 这是本轮候选中双宿主授权和 2026 主机版本支持写得最清楚的一套。它覆盖标题、转场、跟踪、遮罩、抠像、修复、调色和粒子，最接近完整后期工具箱。
2. **要最贴合科普口播的指示、标注、对比、局部放大和操作演示：首选 MotionVFX mTutorial。** 但 Premiere 与 Resolve 是两个独立版本，要各买一份；当前标价合计 **US$238（税前）**。它不是“一个授权跨两端”。
3. **要肤色、降噪、风格化调色、光效和高级转场：考虑 Maxon Red Giant。** 一个 Red Giant/Maxon One 订阅覆盖一套生态，但不是每个插件都同时兼容两个宿主；官方兼容矩阵对 Resolve 的覆盖明显少于 Premiere，而且本轮页面尚未明确列出 Resolve 20/21，购买前必须用试用版验证。
4. **Film Impact 已并入 Premiere，不支持 Resolve；FXhome 已停止运营。** 两者不应作为新的双平台采购对象。

## 购买建议（面向科普口播）

### 方案 A：最省心、真正双平台

买 **Continuum Multi-host 年订阅**。尤其适合需要在 PR 和 Resolve 之间迁移项目，同时频繁做物体跟踪标注、遮罩、标题、抠像、修复和风格统一。确认购物车产品名里包含 **Adobe + OFX**；只写 Adobe 的许可证不能用于 Resolve。

### 方案 B：最高科普制作效率

分别购买 **mTutorial for Premiere** 和 **mTutorial for DaVinci Resolve**。它对知识讲解的“箭头—圈选—放大—对比—步骤提示”更有针对性，学习成本和时间成本通常低于大型 VFX 套装。若短视频竖屏是主战场，先重点测试 Premiere 版的横屏限制；也可只买 Resolve 版承担包装，再把成片/透明通道素材交回 PR。

### 方案 C：画面品质与风格优先

订阅 **Red Giant**，先用 14 天试用验证自己实际会用的插件在两个宿主是否都出现、能否正常加速和渲染。它更擅长肤色、降噪、电影感、光效、转场，不如 mTutorial 那样直接提供科普标注组件。

### 不建议一次把三套都买齐

对于以口播、图文解释、素材引用为主的科普项目，Continuum 与 Red Giant 在转场、调色、光效等方面会有明显重叠。更合理的组合是：

- 追求双平台完整性：**Continuum Multi-host + Premiere 内置 Film Impact**。
- 追求科普包装效率：**mTutorial 双版本 + 两款软件自带调色/降噪**。
- 已有成熟动态图形模板，只缺画面润色：**Red Giant + Premiere 内置 Film Impact**。

## 核验边界

- 价格采用能在官方页面或官方 2026 MSRP 文件中直接核实的数据；动态购物车未稳定返回的价格没有用第三方数字补齐。
- “支持 Premiere 与 Resolve”不等于每个效果、每个功能、每个版本完全一致，尤其 Red Giant 必须逐插件核对。
- 未把素材订阅站、单纯 LUT 包、MOGRT 模板包或仅适配一种宿主的软件算作真正的综合双平台插件套装。
