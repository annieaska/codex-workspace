# 护肤科普研究台

从 `index.html` 进入共用研究台，或打开 `SK-BEH-001.html`（行为型）与 `SK-RES-001.html`（结果型）独立阅读；同名 JSON 与各自 HTML 的内嵌材料一致，可直接导入研究台。两次实际研究均为 **trial_with_gaps（含关键缺口的试运行）**，不是正式合格研究包。平台兴趣、科学证据质量及覆盖缺口按原始记录保留。

已将认可的界面接入正式入口：左侧六页导航、页内标签、材料分页及右上角“使用帮助”均可使用。先在顶部选择研究任务，再按左侧顺序查看或从任务总览继续当前环节。

查看真实获取成果：进入“证据材料 → 获取成果”，打开条目即可阅读工具实际返回的摘要、正文分节及表格，并查看 DOI、PMID／PMCID、获取渠道、时间、原文链接和仍未取得的内容。“科学来源”可筛选“PubMed 条目”或“PubMed MCP 补取”；来源详情区分原始发现记录与本次补取，不能将历史来源改算成 MCP 新发现。

当前 PubMed 小样覆盖两篇已有文献：结果型一篇取得开放论文主体（摘要、5 个正文分节、2 张表及 6 条附件指针）；行为型一篇在本次开放获取路线中未取得全文。附件指针不代表附件已下载或读完，资助／利益声明仍需补查。新增文献、合格深读和主题检索均为 0；这次只验证既有论文的获取能力。`acquisition-results.json` 保存补取成果，构建时嵌入正式 HTML；研究 JSON 与补取成果分别导出，HTML 导出包含当前任务的补取内容。

YouTube 实际成果已接入：顶部选择“结果型”研究，在“证据材料 → 获取成果”打开视频；也可从“平台线索”的 RES-I01 进入。可查看 American Academy of Dermatology 的账号、发布日期、时长、互动数据快照及原视频链接，并在详情下拉菜单切换“视频资料”“英文自动字幕阅读版”“原始时间片”。字幕在限定高度区域阅读，可下载 TXT／VTT，随当前任务的获取成果 JSON 或完整 HTML 导出保留。此次只有一条已有视频补取，自动字幕未经人工校对，播放／点赞／评论数只是 2026-09-26 获取时的快照；旧记录里的未知字段保留，不因此判定兴趣门槛通过。

页面可原位阅读完整材料、审阅各分支、独立记录科学和兴趣门槛，并冻结审阅、方向与最终包。每次决定须明确实际身份和理由。程序核验结构、引用、哈希和门禁，不替代专业质量判断。主控原始决定、冻结时间和审计内容保留为只读历史；当前工作台修改或继续处理，需要新确认，不能冒用历史确认。

本页不自动搜索。Codex 按唯一 run-config.json 的预算取证，返回真实查询与消耗。工具返回量与实际筛读量分列；未知不填满额，预算算术通过不代表全部执行守约。含关键缺口时只能明确选择试运行，正式方向必须同时通过科学与兴趣门槛。

“保存到本机”依赖当前浏览器；导出 JSON 或 HTML 可跨浏览器保留，页面修改不会自动写回磁盘。HTML 内含材料、获取成果、策略审计副本、代码和冻结内容，没有在线字体或代码库。本轮已用 Chromium 的 file: 路径验证直接打开与导出 HTML 再打开，并检查桌面和 390px 手机宽度；浏览器存储受限时使用文件导出。

第三主题先选择模式并填写目标、核心问题、排除范围和产品角色。S0 通过仅表示任务可交给 Codex 取证，不表示研究完成；其他规则仍绑定唯一策略。

构建：`python3 build_workbench.py --data <行为研究JSON绝对路径> --data <结果研究JSON绝对路径> --split`。构建器从原研究同目录读取外部审计并校验哈希，向成果副本嵌入原始payload；不改原研究或审计文件。成果JSON可直接导入，原始外部审计JSON应先经构建器嵌入payload。`workbench-core.js` 是页面与定向检查共用逻辑。

`demo.html` / `static-fixtures.json` 是保留的阶段2演示，不是真实证据。项目临时目录内测试夹具同样不是实际研究。本次定向验证、截图及往返导出测试副本保留在 `../../02_工作区/99_临时/2026-09-26_UI正式接入/`，其中 `roundtrip-*` 和 `test-request.json` 仅为测试产物；PubMed 原始响应保留在同级 `2026-09-26_PubMed试跑/`，均不自动清理。

YouTube 页面定向验证与原始试跑文件保留在 `../../02_工作区/99_临时/2026-09-26_YouTube试跑/`：`ui-validation.json` 记录 9 项通过，`ui-integrity.json` 核对原研究、PubMed 内容、三 HTML 及字幕一致性；`ui-desktop-video.png`／`ui-mobile-subtitles.png` 为截图，`roundtrip-*` 为下载／导出测试副本。`before-*` 是本轮修改前备份，均保留，不自动清理。本次未重跑与改动无关的研究门槛及冻结操作。
