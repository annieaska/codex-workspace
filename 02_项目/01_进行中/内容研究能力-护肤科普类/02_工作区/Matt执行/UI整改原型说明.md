## 关键业务流

1. 总览看到真实缺口 → 待补证 → 选择 1–2 项 → 预览给研究执行方的交接要求；不伪称研究已启动。
2. 分支审阅 → 阅读当前判断 → 主张与原始来源详情 → 适用边界 → 记录带理由的演示草稿 → 下一分支。
3. 证据材料搜索／翻页 → 单条资料详情 → 返回原列表；任务切换各自保留浏览位置和演示草稿。
4. 候选方向 → 查看科学、兴趣两项门槛 → 对应缺口；关键缺口尚在时不能正式交付。
5. 研究交付 → 当前摘要／版本历史 → 查看现有完整研究包，历史只读。

- 采用真实记录的只读副本；演示草稿只保存在当前页面内存，刷新即清除，不改变研究证据、正式审核、冻结与原文件。
- 新建任务仅演示填写与任务预览；不触发研究、导入、磁盘写入或入库。
